# 智域启算（ZhiYuQiSuan Robot）

## 基于 FPGA 与边缘 AI 的多传感器自主移动机器人系统

本项目面向全国大学生嵌入式芯片与系统设计竞赛（2026 高云半导体赛道），设计并开发一套基于 FPGA 的四轮麦克纳姆轮移动机器人系统，围绕多传感器感知、运动控制、实时避障、自主导航及边缘 AI 视觉扩展开展研究与实现。

## 1. 项目简介

项目以高云半导体 GW5AT-60K FPGA 为核心控制平台，构建机器人底层运动控制与多传感器感知系统。

系统采用模块化设计，实现摄像头图像采集与显示、姿态信息采集、编码器反馈、距离检测、避障控制及路径导航等功能。

在此基础上，扩展 BM1684 边缘 AI 平台与 Astra 深度相机，开展视觉目标识别、深度信息获取及机器人感知融合研究。

## 2. 硬件平台

- FPGA：Gowin GW5AT-60K
- FPGA 开发平台：小梅哥 ACG720
- 主控扩展平台：BM1684
- 运动机构：四轮麦克纳姆轮底盘
- 图像采集：OV5640 摄像头
- 显示接口：HDMI
- 存储：MT41K128M16JT-125 DDR3
- 测距传感器：四路 ToF、超声波模块
- 姿态传感器：IMU
- 反馈检测：四路电机编码器
- 深度视觉扩展：Astra 深度相机

## 3. FPGA 核心功能

1. 四轮麦克纳姆底盘运动控制
2. 电机 PWM 驱动与编码器反馈采集
3. IMU 姿态数据采集与航向角显示
4. OV5640 摄像头图像采集与 HDMI 显示
5. 多方向 ToF 测距与异常恢复机制
6. 超声波辅助测距
7. A5 实时避障控制
8. A6 路径点导航控制
9. 多传感器状态实时显示

## 4. AI 与视觉扩展

基于 BM1684 边缘计算平台，开展以下扩展工作：

- YOLO 目标检测模型部署
- ONNX 模型转换与 BModel 部署
- Astra 深度相机 RGB-D 数据采集
- 视觉目标与深度距离信息融合
- ROS 2 Foxy 节点开发
- FPGA 与边缘计算平台串口通信研究

## 5. 软件开发环境

| 开发方向 | 工具与环境 |

| FPGA 开发 | Gowin EDA |

| 边缘 AI | BM1684、TPU-MLIR |
| 操作系统 | Ubuntu Linux |
| 机器人框架 | ROS 2 Foxy |
| 算法开发 | Python |
| 模型部署 | ONNX、BModel |

## 6. 项目技术路线

第一阶段：完成 FPGA 底层控制平台搭建及基础运动控制。

第二阶段：完成摄像头、IMU、ToF、超声波及编码器等传感器接入。

第三阶段：开展实时避障、路径点导航与运动控制优化。

第四阶段：扩展 BM1684 与 Astra 深度视觉系统，开展 AI 目标识别和多传感器信息融合。
